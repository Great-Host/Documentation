# 🧪 Reseller API: Step by step example

This guide sells a VPS to a new customer from start to finish, using `curl`. Run the commands **on your own server**, never in a browser.

## Before you start
1. In **Products & pricing**, give a price to at least one **VPS KVM** plan and click **Save**.
2. Make sure you have enough GreatHost **credit** for that plan.
3. In **API**, create a key and save it.

Store the values you will reuse in variables:

```bash
export GH="https://greathost.es/api/reseller/v1"
export GH_KEY="ghr_live_xxxxxxxxxxxxxxxx_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

## 1. Check your key
```bash
curl -s "$GH/account" -H "Authorization: Bearer $GH_KEY"
```
You should see `"success": true` and your store.

## 2. Look at what you can sell
```bash
curl -s "$GH/vps/catalog" -H "Authorization: Bearer $GH_KEY"
```
Write down a `productId` from `plans` and an `id` from `operatingSystems`:

```bash
export PRODUCT="<productId>"
export OS="debian-12"
```

## 3. Register the customer
```bash
curl -s -X POST "$GH/customers" \
  -H "Authorization: Bearer $GH_KEY" -H "Content-Type: application/json" \
  -d '{"email":"jane@example.com","password":"a-strong-password","fullName":"Jane Doe"}'
```
Save the `customerToken` from the answer:

```bash
export CT="<customerToken>"
```

If the customer already exists, sign them in instead:
```bash
curl -s -X POST "$GH/customers/login" \
  -H "Authorization: Bearer $GH_KEY" -H "Content-Type: application/json" \
  -d '{"email":"jane@example.com","password":"a-strong-password"}'
```

## 4. Order the VPS
Charge your customer in your own app first. Then:

```bash
curl -s -X POST "$GH/orders" \
  -H "Authorization: Bearer $GH_KEY" -H "X-Customer-Token: $CT" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: order-jane-0001" \
  -d '{"productId":"'"$PRODUCT"'","serviceName":"Jane VPS","vps":{"osId":"'"$OS"'","hostname":"jane-web","password":"JaneRoot2026x"}}'
```
Save the service `id`:

```bash
export SID="<service id>"
```

> **Tip:** If this request times out, run it again **with the same `Idempotency-Key`**. You will get the same answer, not a second VPS.

## 5. Wait until it is ready
```bash
curl -s "$GH/services/$SID/vps/progress" -H "Authorization: Bearer $GH_KEY" -H "X-Customer-Token: $CT"
```
Repeat every few seconds until `"status": "active"` (usually 2-5 minutes).

## 6. Get the access details
```bash
curl -s "$GH/services/$SID/vps/credentials" -H "Authorization: Bearer $GH_KEY" -H "X-Customer-Token: $CT"
```
Your customer can now connect: `ssh root@<host>`.

## 7. Control it
See its state:
```bash
curl -s "$GH/services/$SID/vps" -H "Authorization: Bearer $GH_KEY" -H "X-Customer-Token: $CT"
```

Restart it:
```bash
curl -s -X POST "$GH/services/$SID/vps/power" \
  -H "Authorization: Bearer $GH_KEY" -H "X-Customer-Token: $CT" -H "Content-Type: application/json" \
  -d '{"action":"restart"}'
```

Create a backup:
```bash
curl -s -X POST "$GH/services/$SID/vps/backups" \
  -H "Authorization: Bearer $GH_KEY" -H "X-Customer-Token: $CT" -H "Content-Type: application/json" \
  -d '{"rotate":true}'
```

Open the browser console:
```bash
curl -s "$GH/services/$SID/vps/console" -H "Authorization: Bearer $GH_KEY" -H "X-Customer-Token: $CT"
```

## 8. Billing
Decide how it renews. Manual renewals only (you call `/renew` when your customer pays):
```bash
curl -s -X PUT "$GH/services/$SID/vps/auto-renew" \
  -H "Authorization: Bearer $GH_KEY" -H "X-Customer-Token: $CT" -H "Content-Type: application/json" \
  -d '{"enabled":false}'
```

Renew one cycle (charged to your credit):
```bash
curl -s -X POST "$GH/services/$SID/renew" -H "Authorization: Bearer $GH_KEY" -H "X-Customer-Token: $CT"
```

Add an extra IPv4, billed to your customer at 4.00 per cycle:
```bash
curl -s -X POST "$GH/services/$SID/vps/ips" \
  -H "Authorization: Bearer $GH_KEY" -H "X-Customer-Token: $CT" -H "Content-Type: application/json" \
  -d '{"priceCents":400}'
```

## 9. Cancel
At the end of the paid period:
```bash
curl -s -X POST "$GH/services/$SID/cancel" \
  -H "Authorization: Bearer $GH_KEY" -H "X-Customer-Token: $CT" -H "Content-Type: application/json" \
  -d '{"reason":"Customer request"}'
```

Changed your mind:
```bash
curl -s -X POST "$GH/services/$SID/resume" -H "Authorization: Bearer $GH_KEY" -H "X-Customer-Token: $CT"
```

Delete it now, with all its data (cannot be undone):
```bash
curl -s -X POST "$GH/services/$SID/cancel" \
  -H "Authorization: Bearer $GH_KEY" -H "X-Customer-Token: $CT" -H "Content-Type: application/json" \
  -d '{"immediate":true,"confirm":true}'
```

## Check the result in your panel
Everything you did appears in the Reseller Panel: the customer in **Customers**, the VPS in **Services**, the order and renewals in **Invoices**, the money in **Earnings** and every action in **Activity**.
