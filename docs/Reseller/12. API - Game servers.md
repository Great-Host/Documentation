# 🎮 Reseller API: Game servers

These endpoints control a game server (Minecraft Paper). All of them need `Authorization` and `X-Customer-Token`, and work only on services of that customer.

The sections you disabled in **Storefront → Control panel** are also disabled here (`FEATURE_DISABLED`). While a service is **suspended** it is read-only.

| Method | Path | Body / query | What it does |
|---|---|---|---|
| GET | `/services/:id/overview` | | Status, address, resource usage and limits. |
| GET | `/services/:id/console` | | Recent console output. |
| POST | `/services/:id/console/command` | `{ "command": "say hello" }` | Sends a console command. |
| POST | `/services/:id/power` | `{ "action": "start" }` | `start`, `stop`, `restart` or `kill`. |
| GET | `/services/:id/files` | `?directory=/` | Lists a folder. |
| GET | `/services/:id/files/contents` | `?file=/server.properties` | Reads a text file. |
| POST | `/services/:id/files/write` | `{ "file": "/motd.txt", "content": "Hi" }` | Creates or overwrites a file. |
| POST | `/services/:id/files/folder` | `{ "directory": "/", "name": "plugins" }` | Creates a folder. |
| POST | `/services/:id/files/new` | `{ "directory": "/", "name": "notes.txt" }` | Creates an empty file. |
| POST | `/services/:id/files/delete` | `{ "directory": "/", "names": ["old.log"] }` | Deletes files or folders. |
| POST | `/services/:id/files/rename` | `{ "directory": "/", "from": "a.txt", "to": "b.txt" }` | Renames or moves. |
| GET | `/services/:id/startup` | | Startup variables. |
| PUT | `/services/:id/startup/variable` | `{ "key": "MINECRAFT_VERSION", "value": "latest" }` | Changes a startup variable. |

## Examples
Start the server:
```bash
curl -X POST https://greathost.es/api/reseller/v1/services/$SID/power \
  -H "Authorization: Bearer $GH_KEY" -H "X-Customer-Token: $CT" \
  -H "Content-Type: application/json" \
  -d '{"action":"start"}'
```

Send a command:
```bash
curl -X POST https://greathost.es/api/reseller/v1/services/$SID/console/command \
  -H "Authorization: Bearer $GH_KEY" -H "X-Customer-Token: $CT" \
  -H "Content-Type: application/json" \
  -d '{"command":"whitelist add Steve"}'
```

## Notes
- Right after an order, the server is still installing for a few minutes. Most actions answer `INSTALLING` (409) until it finishes.
- Limits: 10 power actions and 60 console commands per minute per service, 60 file changes per minute per service.
